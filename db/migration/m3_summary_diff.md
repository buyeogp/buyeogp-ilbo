# 종합일보 ↔ 개별일보 대조

본사 종합일보(재입력본)의 돈사별 「두수합계 · 전일두수」를
현장 개별일보에서 같은 값을 합산해 맞대봤다.

## 정렬 확인

종합일보 시트 `MMDD` 의 전일두수가 개별일보의 어느 날짜와 맞는지 먼저 확정했다.

| 시트 날짜 대비 | 일치 / 비교 |
|---|---|
| +0일 | 120 / 120  ← 채택 |
| -1일 | 38 / 114 |
| +1일 | 45 / 126 |

## 결과

- 비교 가능 조합: **120**  (돈사 6개 × 겹치는 일자)
- 일치: **120**
- 불일치: **0**  (0.0%)

## 분류 체계가 서로 다르다 (D1)

두 문서는 같은 돈사를 다른 축종구분으로 쪼갠다.

```
순치사   개별일보  후보(수) · 후보(암) · 이유모돈 · 체류돈 · 임신돈
         종합일보  후보(암) · 웅돈 · 도태대기 · 이유모돈 · 장기체류돈 · 임신돈
종부사   개별일보  웅돈 · 후보(암) · 이유돈 · 단기체류 · 장기체류 · 임신돈
         종합일보  후보(암) · 단기체류(이유모돈) · 장기체류 · 도태대기 · 임신돈
```

항목 단위로는 대조 자체가 불가능하고 합계로만 맞댈 수 있다.
같은 사실을 세 곳에 서로 다른 구조로 적고 있다는 뜻이며,
신규 시스템에서 종합일보를 뷰로 만들면 이 불일치가 원천적으로 사라진다 (설계문서 §4.13).
